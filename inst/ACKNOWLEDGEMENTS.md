# Code provenance and acknowledgements

The deepICMGP authors adapted code from the **deepgp** R package to implement deep intrinsic coregionalization Gaussian processes. deepgp is the software foundation for this implementation, not only a runtime dependency.

The underlying deep Gaussian process methodology is described in:

Sauer, A., Gramacy, R. B., and Higdon, D. (2023). *Active Learning for Deep Gaussian Process Surrogates*. Technometrics, 65(1), 4–18. https://doi.org/10.1080/00401706.2021.2008505

Software source: https://CRAN.R-project.org/package=deepgp
Software DOI: https://doi.org/10.32614/CRAN.package.deepgp

Use `citation("deepgp")` for the software citation corresponding to the installed version. The exact historical deepgp version from which code was originally adapted has not been recorded here; the version installed for validation is not necessarily that original version. Existing attribution notices are retained. This acknowledgement does not select or change deepICMGP's software license.
